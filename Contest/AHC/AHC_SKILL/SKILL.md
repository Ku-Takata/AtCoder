# AHC (AtCoder Heuristic Contest) 開発・実験ガイドライン

## 1. 最重要制約（コンテストルール遵守）
- **GitHub等への公開禁止**:
  AHC期間中、コードやログをGitHub等の外部リモートリポジトリへ `git push` やアップロードをする提案・操作は一切禁止する。すべての操作はローカル環境内で完結させること。

## 2. 実験プロセスと再現性の確保（Harness & Reproducibility）
- **シード値の固定**:
  乱数生成（`std::mt19937` 等）のシード値は必ず固定し、同じ入力・同じパラメータであれば100%同じ実行結果が得られる（再現性がある）コードにすること。
- **標準ハーネスでの検証**:
  コードのスコア検証は、単一ケースではなく決められた複数シード（例: seed 0〜49の50ケース）を一括実行し、平均スコア・合計スコア・最悪ケースを算出して比較すること。

## 3. 実験ログの記録義務（`EXPERIMENTS.md`）
試したことの重複を防ぎ、改善・分析を蓄積するため、コード変更や実験を行うたびにプロジェクト直下の `EXPERIMENTS.md` に以下の形式で記録を更新・追記すること。

### ログフォーマット
```markdown
## 実験 #N: [変更の概要タイトル] (日時: YYYY-MM-DD HH:MM)
- **仮説・目的**: なぜこの変更を行うのか、何を狙っているのか
- **変更内容**: 変更した処理やパラメータ
- **結果**:
  - 変更前スコア (50ケース): [平均 / 合計]
  - 変更後スコア (50ケース): [平均 / 合計]
  - 差分: [+XX,XXX / -XX,XXX]
- **分析・考察**: `cerr` のデバッグ出力などから分かったこと
- **採否**: [採用 / 却下 / 保留]
