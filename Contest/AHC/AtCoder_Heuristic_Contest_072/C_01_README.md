# C_01

`B_10_IMPROVEMENT_SPEC.md`に基づき、`B_series/B_09.rs`から作成した提出用の単独Rustファイルです。外部クレートは不要です。

## 実装

- 改善A: prefix盤面・累積帰巣数・操作両端をキャッシュします。変更区間だけを置換して後続を再生し、元の状態へ合流した時点で検証を終了します。高さと色列を厳密に比較し、ハッシュ一致だけで採用しません。既存5種類の幾何学的短縮とprune/cycleで共通検証器を使います。
- 改善B: 元の3～8手を2手へ置換します。空の同一直線中継点と直交コーナーを含め、1手目の帰巣後の高さから合法なk2を列挙します。完全一致候補を先に、他の候補を差分検証で評価します。
- 改善C: 最大12マスの96バイト状態を使う反復深化DFSです。3～6手の窓を最大4手・2,000ノード・1ms/窓で探索し、終了状態が完全一致した置換だけを採用します。最大24手区間から独立操作を残す版も含みます。端点集合の閉包を固定点まで求め、採用時は区間全体の実再生でも全盤面一致を確認します。
- A44側のSAは1,400msを維持します。幾何学的短縮は1,650msまで、新2手置換は最大30ms、小領域探索は最大50ms、最終整理は1,750msまでです。各新探索には実際の締切を渡します。時間切れでは検証済みの解を保持します。
- B01側の解生成・フォールバックを維持しています。共通後処理の差分検証はB01側でも使いますが、新2手置換と小領域探索はA44側だけに追加しています。
- 改善Dの候補内容による重複判定・公平な時間配分は含めていません。

## コンパイル・切替

作業フォルダで実行します。

```powershell
rustc --edition=2021 -O C_01.rs -o C_01.exe
rustc --edition=2021 -O --test C_01.rs -o scratch\C_01_tests.exe
.\scratch\C_01_tests.exe
```

| 引数 | 後処理 |
|---|---|
| `--post=fast` | 改善A。元のLNS・後処理パイプラインを維持 |
| `--post=bridge` | 改善A+B。残り予算に余裕があれば従来LNSも実行 |
| `--post=local-contiguous` | 改善A+B+Cの連続窓版 |
| `--post=local` | 改善A+B+C、独立操作を残す版を含む。標準設定 |

今回の100ケース比較は標準設定を使います。各切替設定の性能比較は実行していません。
